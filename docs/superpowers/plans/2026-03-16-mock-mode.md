# MSW Mock Mode Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `npm run dev:mock`으로 서버 없이 앱을 실행할 수 있도록 MSW 기반 전체 API mock 환경을 구성한다.

**Architecture:** MSW(Mock Service Worker)가 브라우저 Service Worker로 등록되어 모든 axios 요청을 네트워크 레벨에서 가로챈다. `main.tsx`의 `prepare()` 함수가 React 렌더 전에 MSW를 시작하고, `initMockSession()`으로 `pms-auth` localStorage를 사전 세팅하여 `restoreSession`이 즉시 인증에 성공하게 한다.

**Tech Stack:** MSW 2.x, cross-env, Vite env vars (`VITE_MOCK`), Web Crypto API (RSA-OAEP)

**Spec:** `docs/superpowers/specs/2026-03-16-mock-mode-design.md`

---

> **테스트 방법:** 이 기능은 UI 연동 테스트가 주다. 각 태스크 완료 후 `npm run dev:mock`으로 서버를 실행하고 브라우저에서 확인한다. 프로젝트에 테스트 러너(vitest/jest)가 없으므로 TDD 대신 단계별 브라우저 smoke test로 검증한다.

- [ ] **Step 1: `src/mocks/initMockSession.ts` 생성**

`App.tsx:56-59`의 `restoreSession`이 `authStore.user.usrId` 없으면 즉시 logout 처리한다.
MSW 시작 전에 `pms-auth` localStorage를 세팅해야 refresh→getMe 흐름이 진행된다.
Zustand persist 포맷: `{ state: { user, roles }, version: 0 }`.

```ts
const PMS_AUTH_KEY = 'pms-auth';

export function initMockSession(): void {
  if (localStorage.getItem(PMS_AUTH_KEY)) return; // already set
  localStorage.setItem(
    PMS_AUTH_KEY,
    JSON.stringify({
      state: {
        user: { usrId: 'admin', usrNm: '관리자', email: 'admin@example.com' },
        roles: ['ROLE_ADMIN'],
      },
      version: 0,
    }),
  );
}
```

- [ ] **Step 2: `src/mocks/clearMockCache.ts` 생성**

`labelStore`/`comcdStore`의 IndexedDB TTL 캐시가 실서버 데이터를 5분간 유지하므로
mock 모드 시작 전에 `ds-pms-cache` DB를 삭제한다.
`deleteDatabase`는 비동기이므로 완료 후 MSW를 시작하도록 Promise로 래핑한다.

```ts
const DB_NAME = 'ds-pms-cache'; // src/lib/cache/idbCache.ts의 DB_NAME과 동일

export function clearMockCache(): Promise<void> {
  return new Promise((resolve) => {
    const req = indexedDB.deleteDatabase(DB_NAME);
    req.onsuccess = () => resolve();
    req.onerror = () => resolve();    // failure is non-critical
    // onblocked: other connections hold the DB open — wait briefly then continue
    req.onblocked = () => setTimeout(resolve, 300);
  });
}
```

```ts
import { http, HttpResponse } from 'msw';
import { MOCK_RSA_PUBLIC_KEY } from '../data/rsaKey';
import { BASE_URL } from '../config';

export const authHandlers = [
  // GET /api/auth/public-key
  // fetchPublicKey() reads (data as any).data?.publicKey — ApiResponse wrapped
  http.get(`${BASE_URL}/api/auth/public-key`, () => {
    return HttpResponse.json({ status: 200, data: { publicKey: MOCK_RSA_PUBLIC_KEY } });
  }),

  // POST /api/auth/login
  // LoginPage/api.ts calls apiClient.post<LoginResponse> — raw response, no ApiResponse wrapper
  http.post(`${BASE_URL}/api/auth/login`, () => {
    return HttpResponse.json({
      accessToken: 'mock-access-token',
      refreshToken: 'mock-refresh-token',
      tokenType: 'Bearer',
      expiresIn: 3600,
    });
  }),

  // POST /api/auth/refresh
  // App.tsx restoreSession + client.ts silent refresh — raw LoginResponse
  http.post(`${BASE_URL}/api/auth/refresh`, () => {
    return HttpResponse.json({
      accessToken: 'mock-access-token',
      refreshToken: 'mock-refresh-token',
      tokenType: 'Bearer',
      expiresIn: 3600,
    });
  }),

  // POST /api/auth/logout
  http.post(`${BASE_URL}/api/auth/logout`, () => {
    return HttpResponse.json({ status: 200, success: true, message: 'success', data: null });
  }),
];
```

```tsx
    const { clearMockCache } = await import('./mocks/clearMockCache');
    const { worker } = await import('./mocks/browser');

    initMockSession();
    await clearMockCache();
    await worker.start({ onUnhandledRequest: 'bypass' });
  }
}

prepare().then(() => {
  createRoot(document.getElementById('root')!).render(
    <QueryClientProvider client={queryClient}>
      <App />
    </QueryClientProvider>
  );
});
```

> **주의:** `import.meta.env.VITE_MOCK` 가드가 없으면 Vite의 dynamic import가 prod 빌드에 MSW를 포함시킬 수 있다. 현재 코드처럼 `if (VITE_MOCK === 'true')` 블록 안에서만 import해야 한다.
