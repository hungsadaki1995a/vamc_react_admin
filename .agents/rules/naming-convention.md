# Source Code Naming Conventions

Follow these naming conventions for all source code in this project:

| Item | Convention | Example |
| :--- | :--- | :--- |
| Folder names | `kebab-case` | `customer-management/` |
| React component filenames | `PascalCase` | `CustomerTable.tsx` |
| React component names | `PascalCase` | `CustomerTable` |
| Hook filenames | `use-kebab-case` | `use-customers.ts` |
| Hook function names | `camelCase` | `useCustomers()` |
| Utility filenames | `kebab-case` | `format-currency.ts` |
| Functions and variables | `camelCase` | `formatCurrency` |
| Types and interfaces | `PascalCase` | `CustomerResponse` |
| Constants | `UPPER_SNAKE_CASE` when appropriate | `MAX_PAGE_SIZE` |
